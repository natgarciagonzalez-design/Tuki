Nombre del proyecto

La Rosa Negra

¿De qué trata?

La Rosa Negra es una página web de un restaurante temático inspirado en la estética gótica y vampírica. El sitio presenta un diseño oscuro con colores rojos y negros, animaciones, murciélagos decorativos y una ambientación elegante y misteriosa.

La página incluye un menú de navegación interactivo, una sección “Sobre Nosotros” con la historia ficticia del restaurante, una lista de platos temáticos con imágenes y efectos visuales, además de los servicios que ofrece el local. Todo fue desarrollado utilizando HTML y CSS.
